# 🕋 Umrah Operations System (نظام عمليات الحج والعمرة)

A comprehensive enterprise operations system designed for Umrah and Hajj service providers, agencies, and tour operators.

---

## 📁 Repository Structure

- `Umrah-frontend/`: Modern React 19 + TypeScript + Vite + Tailwind CSS frontend web application.

---

## 🌟 Modules & Core Capabilities

- **لوحة التحكم (Dashboard)**: Overview metrics, pilgrim demographics, and activity streams.
- **إدارة المجموعات (Groups)**: Multi-step pilgrim group onboarding wizard with hotel, flight, transport, and permit allocations.
- **إدارة الفنادق (Hotels)**: Hotel directories, room types, pricing, and ratings.
- **إدارة الرحلات (Trips)**: Inter-city journeys, flights, and guide management.
- **النقل والأسطول (Transport & Fleet)**: Transport company listings, vehicle inventories (VIP buses, sedans, coasters), and maintenance status.
- **الاتفاقيات والعقود (Contracts & Agreements)**: Official agreement generation with print-ready PDF export.
- **الملاحظات التشغيلية (Operations Notes)**: Filterable task & issue log with status tagging.

---

## 🚀 Quick Start

```bash
# Navigate to frontend
cd Umrah-frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
